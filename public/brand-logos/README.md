# Brand logos

Drop a logo file here named after the brand (lowercase, hyphenated). The site
falls back to it when an OILS product has no images of its own.

Naming convention: lowercase, non-alphanumerics → hyphen.
- "Shell"   → `shell.svg` / `shell.png`
- "Castrol" → `castrol.svg`
- "Mobil 1" → `mobil-1.svg`

Accepted extensions (first match wins): `svg`, `png`, `webp`, `jpg`, `jpeg`.
